The **Bio-Inspired Robotics Testbed (BRT)** aims to bridge robotics and biology by aggregating MuJoCo simulation environments of animals. It serves two communities: for roboticists, it provides benchmarks for the design and control of bio-inspired robots; for biologists, it offers robots as a controlled comparative method for studying behavior, ecology, and evolution.
